# 💻 Ideal Developer Workstation

Customized Linux developer environment engineered for consistency, productivity, and keyboard-driven navigation.

---

## 🎨 Theme & Appearance

* **Icon Theme:** Breeze Chameleon Dark
* **Color Palette:** Bali 10050's Dark
* **Terminal Theme:** Monokai Charcoal (`alacritty.toml`)
* **System Fetch:** Fastfetch (`config.jsonc`)

---

## ⌨️ Keyboard Shortcuts & Keybindings

| Action | Shortcut / Keybinding |
| :--- | :--- |
| **Open Terminal (Alacritty)** | `Ctrl` + `Space` |
| **Open System Monitor (btop)** | `Super` + `Z` |
| **Application Launcher** | `Super` + `D` *(or your custom launcher key)* |
| **Workspace Switching** | `Super` + `1-9` |
